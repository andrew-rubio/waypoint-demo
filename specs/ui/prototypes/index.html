Waypoint

Interactive wireframe prototypes for the Waypoint holiday-planning agent, built on the GitHub Copilot SDK. Browse each app state below. The audit-trail panel toggles from the header on every screen.

S1 · FRD-001

Welcome

First-run empty state with suggested prompts and the composer.

 S2 · FRD-003/004/005/006

Active conversation

Streamed replies with destination, weather, flight and hotel cards.

Trip summary & booking

Itinerary card, GBP/EUR budget, applied preferences & points, simulated confirmation.

Audit trail open

The hero view — live decisions, MCP and API calls with timing and status.

Degraded & errors

Wireframes only — realistic placeholder data, no live services. Prices in GBP by default (EUR on request). Synthetic traveller: John Doe (Gold tier).
