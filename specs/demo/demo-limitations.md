# Demo limitations & non-claims

State these explicitly during the walkthrough. Claim vocabulary:
`Implemented and automatically tested` · `Implemented and shown live` · `Implemented but
prerecorded` · `Deterministic synthetic fixture` · `Represented architecturally` ·
`Proposed future IAG-specific capability` · `Not implemented`.

This repository alone does NOT implement:
- IAG's authoritative standards repository (synthetic catalogue only).
- A Group-wide factory control plane.
- Enterprise approval identity (approval is hash-bound + self-asserted, no non-repudiation).
- Production cross-cloud portability of complete agents.
- Automatic cross-provider model rerouting (stale-currency is deterministic app containment).
- Full cost attribution (schema-only, no values).
- Durable Functions multi-day orchestration (narrative-only).
- Regulatory certification.

Runtime-proof honesty: if the portal/trace/correlation proof is unavailable, state that
runtime hosting is not independently verified for that execution — never present the local
driver behind a Foundry badge.
